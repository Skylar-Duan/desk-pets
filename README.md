# desk-pets · 桌面小伙伴

独立Windows桌面宠物软件：像素布偶猫「小布」、像素金毛「阿金」、现代玩具风布偶猫「糯米」、现代金色寻回猎犬「洛洛」。在控制窗口勾选想展示的动物，常驻桌面。
灵感对标 OpenAI Codex 桌宠的审美与克制感，但完全独立、零依赖、全离线。

## 功能

- **选择宠物**：小布、阿金、糯米、洛洛各自勾选，选择与装饰设置自动记住；关控制窗口后继续运行。默认小布、糯米、洛洛；升级时用洛洛接替原先选中的阿金，像素阿金仍可再勾选
- 宠物在屏幕底部游走、奔跑、坐卧、打盹；金毛会时不时跑去找同伴
- **活跃度感知**：她在打字干活，宠物就精神；人离开几分钟，宠物睡大觉（只读系统"距上次键鼠输入的秒数"，不记录任何按键内容）
- **默认可拖**：身体可以摸摸、拖动、抛落，透明区域穿透鼠标；可临时禁用互动，整只宠物完全穿透
- **独立大小**：每只动物各自调节50–200%，自动记住；现代动物各状态统一体型，按实际脚底贴地
- **三款低矮背景**：苔绿小径、暖砂石滩、云朵小窝；默认关闭，高度32–160、透明度0–100%可调；高度随屏幕缩放，最多占工作区底部20%；背景始终穿透鼠标，位置在任务栏上方
- 托盘图标：双击打开选择窗口；右键隐藏/召唤已选宠物、开机自启开关（默认关）、退出
- 不进任务栏、不抢焦点、单实例

## 交付/安装

当前版本 **1.1.0**。打包：`build.bat` 后运行 `powershell -File scripts/package.ps1`，得到 `dist/桌面小伙伴-1.1.0.zip`；包含 exe、四款宠物、三款背景和使用说明。本轮修改沿用1.1.0。

本机安装：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install-local.ps1`。它正常退出旧实例、复制核对文件、创建桌面与开始菜单的「桌面小伙伴」快捷方式并打开软件；安装到 `%LOCALAPPDATA%/Programs/DeskPets/`。无须管理员权限，使用系统自带 .NET Framework 4.8。

也可以解压后直接运行。设置在 `%LOCALAPPDATA%/DeskPets/settings.json`，覆盖更新不改用户选择。关闭控制窗口只是收起；退出软件使用窗口或托盘的「退出」。

## 构建

```
build.bat
```

用 Windows 自带的 csc.exe 编译（C# 5 语法约束），任何 Win10/11 机器都能构建，无需安装任何工具链。

## 素材规范（换装/数字化真猫狗都按这个来）

`pets/<id>/` 一个文件夹 = 一只宠物：

- `pet.json`：`name` / `frameSize [w,h]` / `scale` / `states{ 状态: {file, frames, fps, loop} }`
- 可选 `pixelArt` / `playful` / `baseSizePercent`（默认100，发布时校准整体体型）；状态可带 `leftFile` 保留独立左向步态、`poseScale`（0.25–1）校准跨动作体型。源单格放大后宽高不超过192像素，校准后的100%窗口不超过288像素，再按用户选择的50–200%缩放
- 每个状态一条横向帧条 PNG（透明底，帧等宽）
- 状态集：`idle walk run sit sleep drag fall happy`；缺的状态自动按回退链补
  （walk→idle，run→walk，sit→idle，sleep→sit，fall/drag 互补，happy→idle）
- **换素材 = 换文件夹**。新增文件夹进入控制窗口，勾选才加入桌面；缺动作的回退仅为容错，不代表美术已齐全

像素素材由 `assets-src/gen_pets.py` 生成。糯米由已验收v2素材加新睡眠、提起、下落姿态组成；生成来源和可复现裁切入口见 `assets-src/nuomi/desktop-source/`，运行皮肤在 `pets/nuomi/`。
以后把真猫真狗数字化：照片 → 逐状态画帧条（AI 生成 + 手修，或委托像素画师）→ 落同规范文件夹即可。

**宠物发布体型验收（用户2026-10-14指定）**：新宠物在100%时必须与小布、阿金及已校准糯米的可见体型协调；以同一桌面比例并排比较正常站姿/坐姿，结合头部大小和身体体量，不能按透明格子尺寸判断，也不能依赖用户额外调大小才协调。保留角色自然身形差异；八种动作、左右方向应保持同一只动物的头身尺度，睡姿只改变姿势。发布前检查100%并排总览、全状态体型与贴地、50–200%缩放和拖动抛落。三只当前100%均采用上一轮已校准版本的150%体型；糯米先有1.2倍校准，再统一放大1.5倍，保持三只协调。

## 网页预览（web/）

`web/` 是网站介绍和互动预览：四款宠物用已校准的桌面素材在网页里真实跑动（可点可拖可甩），
附全状态图鉴、皮肤规范和下载按钮。由 10-Platform 挂载到 cdpandas.com 工具站子路径。
本地预览：任意静态服务器指向 `web/` 即可（如 `python -m http.server --directory web`）。
素材同步：`powershell -File scripts/sync-web.ps1`，导出桌面加载器校准后的100%帧，保留左右方向、各状态体型及实际脚底位置；同步三款背景。网页支持演示宠物选择、50–200%大小和三款背景；浏览器减少动态效果设置会暂停自动活动。
网页采用10-Platform工具页统一模板；发布使用 `finance/scripts/publish_utility.py --tool desk-pets --src <本工程web绝对目录>`，遵守工具页契约，独立提交/推送/局部发布，不重建平台镜像。

网页图鉴保留四款伙伴的全部32种动作。预览背景以三个按钮切换淡纯色桌面，固定0%透明度、装饰下对齐；高度/透明度调节保留在桌面软件。页面脚本和样式使用内容哈希文件名，更新后避免读取浏览器旧缓存。

洛洛的基准与安静姿态采用用户自有千问资产，散步/奔跑采用内置imagegen修正帧；原图、提示词、计量与复现入口见 `assets-src/lolo/`。保留双方候选，以实际逐帧质量选择，八种状态共30帧。

## 结构

```
src/           C# 源码（NativeMethods / PetDef / PetWindow / PetBrain / PetManager / TrayContext / Program）
assets-src/    素材生成器
pets/          宠物素材（可整体替换）
backgrounds/   三款低矮背景素材
scripts/       打包、本机安装、素材与Windows窗口属性检查
web/           网站预览页（静态自包含，交 10 部署）
dist/          交付包（gitignore，build 后生成）
build.bat      一键构建
```
