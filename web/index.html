全离线 · 零依赖 · 整包 24KB · 不挡鼠标不抢焦点

↓ 下面就是真实效果 —— 点它摸摸头，按住拖起来甩出去试试 ↓

⬇ 下载 Windows 版（24KB）

解压 → 双击 DeskPets.exe 即可 · Windows 10/11 免安装零依赖
首次运行如遇 SmartScreen 提示：更多信息 → 仍要运行（仅一次）

🐾 活的，不是贴图

散步、奔跑、坐着发呆、打盹；金毛还会时不时跑去找猫。每个动作 1–3 秒的克制循环，陪伴而不打扰。

⌨️ 懂你的节奏

你在打字它们就精神，你离开一会儿它们睡大觉。只读"距上次键鼠输入多少秒"这一个数字，不记录任何内容。

🖱️ 摸得着，扔得动

点一下摸摸头会开心冒爱心；按住拖走、甩出去有抛物线和落地小弹跳。

👻 完全不碍事

宠物身体之外的像素全部点击穿透；不进任务栏、不抢焦点，浮在所有窗口之上默默陪着。

🪶 轻到离谱

整包 24KB，内存约 30MB，CPU 约 3%。用 Windows 自带运行库，一个 exe 加一个素材文件夹，删掉即卸载。

🎨 换装零门槛

一个文件夹就是一只宠物：配置 JSON + 每个动作一条帧图。换素材不用改一行代码，未来支持上传自制皮肤。

皮肤规范（自制换装）

pets/<名字>/ 一个文件夹 = 一只宠物：每个状态一条横向帧条 PNG（透明底、帧等宽）+ 一个 pet.json：

{
  "name": "小布",
  "frameSize": [32, 24],
  "scale": 3,
  "states": {
    "idle":  { "file": "idle.png",  "frames": 4, "fps": 3,  "loop": true },
    "walk":  { "file": "walk.png",  "frames": 4, "fps": 8,  "loop": true },
    "sleep": { "file": "sleep.png", "frames": 2, "fps": 2,  "loop": true }
  }
}

状态全集 idle / walk / run / sit / sleep / drag / fall / happy；缺的状态自动回退（如没画 run 就用 walk）。把文件夹丢进 pets/，重启即生效。
