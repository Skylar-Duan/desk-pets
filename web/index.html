点一下摸摸，按住拖起来，松手会落地。 这里可试玩同一套桌面动作。

桌面预览

网页展示动画与拖动；桌面版还会按你的键鼠活跃度安排休息。演示设置仅影响此页。

它是什么样的

陪着你，但不打扰你。

选你喜欢的伙伴

小布、糯米和现代金毛洛洛独立选择，像素阿金也保留。用新管理窗口单独拖动大小，或联动伙伴与背景；选择会自动记住。

懂你的节奏 不记录内容

你在打字它们就精神，你离开一会儿它们睡大觉。只读「距上次键鼠输入多少秒」这一个数字，不记录任何按键内容。

摸得着，扔得动

点一下会开心回应；按住拖走，甩出去有抛物线和落地小弹跳。默认可以拖动，也能随时临时禁用互动。

工作优先

身体之外的透明区域点击穿透，不进任务栏、不抢焦点。需要专心时，隐藏全部，或让宠物完全穿透鼠标。

每只大小独立调

每只50%至300%独立调整，互不影响。100%默认体型协调，坐下、散步、睡觉也保持同一只动物的比例。

一点桌面风景

三款背景可选，高度和透明度可调；最多占工作区底部20%，位于任务栏上方。背景始终穿透鼠标。

全状态图鉴

四款伙伴，八种状态。按相同100%基准展示，左右滑动查看全部动作。

自己做一只（皮肤规范）

pets/<名字>/ 一个文件夹 = 一只宠物：每个状态一条横向帧条 PNG（透明底、帧等宽），加一个 pet.json：

{
  "name": "小布",
  "frameSize": [32, 24],
  "scale": 3,
  "states": {
    "idle":  { "file": "idle.png",  "frames": 4, "fps": 3,  "loop": true },
    "walk":  { "file": "walk.png",  "frames": 4, "fps": 8,  "loop": true },
    "sleep": { "file": "sleep.png", "frames": 2, "fps": 2,  "loop": true }
  }
}

状态全集 idle / walk / run / sit / sleep / drag / fall / happy。新增文件夹后重启，在控制窗口选择展示。完整素材与说明见GitHub；发布新皮肤前需要校准100%体型、各状态比例和脚底位置。
