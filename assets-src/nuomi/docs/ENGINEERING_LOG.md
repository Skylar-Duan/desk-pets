# 糯米工程过程与决策记录

本记录由现存文件、QA报告和公开操作记录整理，是便于接手的工程说明，不是模型内部隐含思考。

## 目标与设计

用户希望把形象换成“可爱、现代一点的布偶猫”，并使用 Pets 创建、选中宠物。采用奶油白身体、灰褐色耳朵及脸部重点色、白色面部V形、蓝眼睛、粉鼻与蓬松尾巴；从初版偏写实的毛发转为圆润简化的3D玩具质感，保证小尺寸可辨识。

创建提示词、状态依赖、生成结果路径分别位于 work/nuomi/prompts、imagegen-jobs.json 与 decoded。canonical-base.png 为后续一致性参考。不会从目录名称推断用户个人信息。

## 制作流程与修复

| 阶段 | 问题或目的 | 处理与证据 |
| --- | --- | --- |
| 基础角色 | 第一版偏写实 | 生成更简化的现代玩具版本，保存基础图与历史版本 |
| 九种标准动作 | 保持角色、比例、动作含义一致 | 逐行动作生成，再使用插件脚本提帧、检查、配准与拼图；57帧 |
| 向左跑 | 直接按原始等宽槽镜像导致尾巴/口鼻碎片 | 从已配准的向右跑完整单格提取后用插件脚本镜像，保留时间顺序；原始版本保留 |
| 跳跃 | 过大的位移范围导致缩小角色 | 重新生成小跳，用整张已生成姿态的平移控制离地与落地；没有重画身体；最终离地26px、落地基线差1px |
| 等待动作 | 用户发现抬起两前爪后仍保留两落地前腿，形成六肢 | 重新生成整行；抬起两条前肢、仅两后肢支撑，腹部不再保留落地前腿；6帧逐帧及独立验收 |
| 四个方向锚点 | 确保视线方向由头部转动表达 | 上、右、下、左分别生成，身体与脚保持正面稳定 |
| 16视线方向 | 中间方向及跨行过渡有错误 | 第一方向行157.5°残留向右偏转，整行重生；第二方向行末尾误用右上方向，整行重生；方向一致配准 |
| 合成与边缘 | 透明背景、去色边、尺寸与空格要求 | 合成1536×2288的v2图，仅在最终图执行去色边，再对最终字节校验 |
| 验收 | 结构、方向、解剖与动效 | 自动报告、3份方向盲评、最终73帧独立视觉检查与预览 |
| 保存与启用 | 保存资产并启用自定义宠物 | Library文件回读与哈希核对；Pets校验、创建、选择、列表确认 |

## 六肢问题是重要回归项

waiting：两前爪举起后，身体底部只允许两后爪支撑。thinking 和 waving：一条前肢举起，另一条前肢落地，加两后肢，总共四条。不能把举爪动作作为附加肢体覆盖在原有四脚坐姿上。

用户错误示例保留在 references/user-feedback-six-limbs.png；相关修复证据位于 qa/user-feedback.md、qa/waiting-anatomy-independent.md、qa/rows/waiting/anatomy-review.json。最终清理后的 waiting-preview.gif 可直接检查。

## 验收结果与限制

- final/validation-extended.json：ok=true，结构检查无错误或警告，哈希与最终交付一致。
- qa/pet-quality.json：ok=true；跳跃离地26像素，落地偏差1像素。
- qa/direction-blind-validation.json：ok=true，无 errors、warnings 或 unconfirmed。
- qa/final-independent-visual-review.md：PASS；检查最终73个占用格、16方向、waiting、挥手、思考及跳跃相关帧。
- 少数相邻方向差异细微、近基准方向的垂直分量较弱，经记录审查接受；没有声称所有连续性指标都完全无警告。
- 视觉检查包含按序帧和蒙太奇检查，不夸大为所有预览都经过实时播放验收。
- 原有 Library 页面内容和文件引用经过回读；没有声称页面渲染界面经过独立视觉验收。

## 后续修改原则

先保留当前最终图及哈希，再针对需要的整行动作或方向重新生成。变更后重新提帧、配准、合成、去色边、验证与预览；最终图变化后，旧图的QA结论不能直接套用。使用已安装的 Pets 更新能力操作现有 pet_id，执行时重新读取最新技能与账号状态。归档中的插件快照用于理解历史实现。
