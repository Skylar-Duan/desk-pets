# 糯米创作需求

用户希望创建并选中一个新的 ChatGPT Pet，将陪伴形象换为更可爱、更现代的布偶猫。

## 原始请求

Use your create-pet skill to create and select a pet based on what you know about me

这里是要构建啥，我想换个形象，换个可爱现代版本一点的布偶猫，另外pet和dot有关系吗？

## 形象方向

名称：糯米。

描述：一只可爱现代的蓝眼布偶猫，温柔陪伴工作。

采用柔和圆润的现代 3D 玩具风格，奶油白毛，左右对称的灰棕色耳朵与尾巴，白色倒 V 字脸，大蓝眼睛与粉色鼻子。全身轮廓紧凑，毛发蓬松但结构清晰，表情平静、友好、灵动。不添加配饰、文字或品牌标记。

## 动画与使用

创建完整 v2 动画宠物，包含九种动画状态及十六个顺时针视线方向。视线动作保持身体坐定，以自然转头、倾斜头部和眼鼻指向呈现方向。完成验证与动作预览后创建，并按用户请求设为当前 Pet。

## 说明

用户没有提供参考图片。名称、颜色细节与 3D 玩具风格是根据“可爱现代布偶猫”选择的创作方向；不推断其他个人信息。Pet 与 Your dot 的关系依据官方 OpenAI Docs 说明另行解释。
