# 洛洛 · 现代金色寻回猎犬

用户2026-10-14命名。默认体型为上一轮洛洛的150%，独立大小滑杆以此为100%；沿用桌面小伙伴1.1.0。

角色基准和idle/sit/sleep/drag/fall/happy来自用户自有千问资产，模型qwen-image-2.1-pro；散步和奔跑由内置imagegen修正。千问对角色与安静姿态一致性较好且生成较快，但步态候选出现参考坐姿、尾巴边距不足和地面条带；最终按逐帧观感选择两种来源。此结论只对应本次素材，不代表模型的普遍能力排名。

- `base-prompt.json`：用户要求与基准提示词。
- `animation-prompts.json`：动作描述，完整实际请求还保存在每张千问PNG旁的JSON（含参考图哈希、输出计量）。
- `qwen/`：千问原始基准、第一轮及第二轮候选，均保留。
- `builtin/`：内置imagegen基准与修正后的2×2步态；准确修正提示词见`prompts.json`。
- `build_skin.py`：复用糯米交接包的透明主体提取器，选取完整主体、去除外侧碎片，从大图直接配准到384×384运行帧。源图基础比例0.54；下落头部在原图中为154px、静置178px，因此整组另乘1.16，其他状态为1。默认显示75%（288×288画布）。睡眠剔除坐姿参考格；下落只保留最后一格完整悬空姿态，位移由桌面物理提供。没有逐帧拉伸、补画肢体或裁去身体。

最终八种状态共28帧。侧向素材右向为原帧，左向由桌面加载器镜像；同一套校准后帧导出到网页。复现：使用项目Python运行本目录`build_skin.py`，然后`build.bat`、`scripts/package.ps1`和`scripts/sync-web.ps1`。

最新尺度对照在项目`_work/qa/pose-scale/`：所有状态、左右朝向、修复前后对照和量化结果。睡姿的后腿自然遮挡；悬挂和下落检查四肢连接关系。
