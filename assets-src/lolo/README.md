# 洛洛 · 现代金色寻回猎犬

用户2026-10-14命名。与小布、像素阿金、糯米的100%可见体型协调；沿用桌面小伙伴1.1.0。

角色基准和idle/sit/sleep/drag/fall/happy来自用户自有千问资产，模型qwen-image-2.1-pro；散步和奔跑由内置imagegen修正。千问对角色与安静姿态一致性较好且生成较快，但步态候选出现参考坐姿、尾巴边距不足和地面条带；最终按逐帧观感选择两种来源。此结论只对应本次素材，不代表模型的普遍能力排名。

- `base-prompt.json`：用户要求与基准提示词。
- `animation-prompts.json`：动作描述，完整实际请求还保存在每张千问PNG旁的JSON（含参考图哈希、输出计量）。
- `qwen/`：千问原始基准、第一轮及第二轮候选，均保留。
- `builtin/`：内置imagegen基准与修正后的2×2步态；准确修正提示词见`prompts.json`。
- `build_skin.py`：复用糯米交接包的透明主体提取器，选取完整主体、去除外侧碎片，配准到192×192运行帧。按头部尺寸校准动作，走/跑1.10、拖起/下落1.35，其余1.00；睡眠和下落剔除坐姿参考格。没有补画肢体或裁去身体。

最终八种状态共30帧。侧向素材右向为原帧，左向由桌面加载器镜像；同一套校准后帧导出到网页。复现：使用项目Python运行本目录`build_skin.py`，然后`build.bat`、`scripts/package.ps1`和`scripts/sync-web.ps1`。

质量记录在项目`_work/lolo-qa/`：完整轮廓边距、所有状态左右朝向和50–200%大小的脚底位置、拖动释放物理、100%四款同桌比较。睡姿的后腿自然遮挡；悬挂和下落检查四肢连接关系。
